## 🚀 **Quick Start**

### 📥 **Download & Run** *(Recommended)*
1. Download `AutoClicker.exe` and `qt.conf`
2. Double-click `AutoClicker.exe`
3. **No Python installation required!** 🎉

### 🐍 **Run from Source**
```bash
pip install -r requirements.txt
python auto_clicker.py
```

## ✨ **Features**

| Feature | Description |
|---------|-------------|
| 🎯 **Smart Clicking** | Cursor position or fixed coordinates |

| ⌨️ **Global Hotkey** | **F6** - works anywhere! |

| 🎨 **Modern UI** | Clean, intuitive interface |

---

## 🎮 **How to Use**

### 1️⃣ **Configure Settings**
- **⏱️ Interval**: Time between clicks
- **🖱️ Button**: Left/Right/Middle mouse button  
- **📍 Mode**: Cursor location or fixed position
- **🔢 Count**: How many clicks to perform

### 2️⃣ **Start Clicking**
- Press **F6** or click **Start** button
- Press **F6** again to stop

### 3️⃣ **Pick Position** *(Optional)*
- Select "Fixed Position" mode
- Click "Pick Position" button
- Click anywhere on screen to set target

## 🔧 **Troubleshooting**

| Issue | Solution |
|-------|----------|
| 🚫 **App won't start** | Run as Administrator |
