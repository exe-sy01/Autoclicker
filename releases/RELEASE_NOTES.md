# 🖱️ AutoClicker v1.0.0 - Release Notes

## 🎉 **First Stable Release!**

Welcome to the first stable release of AutoClicker - a powerful, modern auto-clicking tool with a sleek interface!

---

## 📥 **Download Instructions**

### **For End Users** *(Recommended)*
1. Download **both files** from this release:
   - `AutoClicker.exe` - The main application
   - `qt.conf` - Configuration file (required)
2. Place both files in the same folder
3. Double-click `AutoClicker.exe` to run
4. **No Python installation required!** ✨

### **For Developers**
- Download the source code or clone the repository
- See README.md for development setup instructions

---

## ✨ **What's New in v1.0.0**

### 🎯 **Core Features**
- **Smart Clicking**: Cursor position or fixed coordinates
- **Lightning Fast**: 1ms to 10 second intervals
- **All Mouse Buttons**: Left, Right, Middle click support
- **Multi-Click**: Single, Double, Triple clicks
- **Flexible Count**: Infinite or limited clicks
- **Global Hotkey**: F6 works anywhere!
- **Position Picker**: Click to select target location
- **Auto-Save**: Settings remembered between sessions
- **Modern UI**: Clean, intuitive interface

### 🛡️ **Safety & Reliability**
- Instant stop with F6 hotkey
- Built-in safety limits
- Thread-safe implementation
- Comprehensive error handling

### 🖥️ **System Compatibility**
- Windows 10/11 (64-bit)
- Standalone executable
- No dependencies required
- DPI awareness support

---

## 🚀 **Quick Start Guide**

1. **Download** both `AutoClicker.exe` and `qt.conf`
2. **Run** the executable
3. **Configure** your settings:
   - Set click interval
   - Choose mouse button
   - Select click mode
4. **Press F6** to start/stop clicking

---

## ⚠️ **Important Notes**

### **Security**
- Some antivirus software may flag the executable as suspicious (false positive)
- This is common with automation tools - add to exclusions if needed
- The application is completely safe and open-source

### **Permissions**
- May require administrator privileges for global hotkey functionality
- Right-click → "Run as administrator" if F6 doesn't work

### **Usage**
- F6 hotkey works system-wide, even when app is minimized
- Both files (`AutoClicker.exe` and `qt.conf`) must be in the same folder
- Settings are automatically saved between sessions
